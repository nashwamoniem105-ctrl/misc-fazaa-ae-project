BUG ANALYSIS - Admin Panel "غير مصرح" Error:

CRITICAL FINDING: The static JS file at /static/js/main.d16c19c9.js returns HTML (index.html) instead of JS!
This means the SPA fallback in server/index.ts is serving index.html for ALL routes including static assets.

The issue:
1. The server has: app.use(express.static(distPath)) - serves static files
2. Then: app.get('/{*path}', ...) - catches all routes and serves index.html
3. BUT the order matters - express.static should be BEFORE the catch-all route

HOWEVER, looking at the code more carefully:
- distPath = path.join(__dirname, '..', 'dist') 
- But the built files are in the repo under 'static/' folder, not 'dist/'!
- The vite.config.ts probably outputs to a different directory

The real issue: The build output from Vite goes to 'dist/' directory, but the repository has 
static files in 'static/' directory. When Railway builds, it might not be using the dist/ folder correctly.

Also: The static JS file returning HTML means the SPA fallback is catching the JS route.
This could be because:
1. The dist/ folder doesn't have the right files after build
2. OR the path is wrong

SOLUTION APPROACH:
1. Fix the server to ensure static files are served correctly
2. Fix the SPA fallback to NOT catch routes starting with /static/ or /assets/
3. Add proper error handling in the frontend when 401 is returned - clear token and redirect to login
4. Add a token verification step on page load before showing the dashboard
